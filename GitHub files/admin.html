📈 Quarterly payroll cycle
Hayley, Tom & Michael are all paid on a quarterly cadence using the trailing-365 (TTM) model. Hayley: enter her last 365 days (last financial year) CM each quarter — CM bands + milestone are applied directly to that figure, then divided by 4 for the quarter's payout (100% paid, no holdback). Tom & Michael: same model on their last 365 days performance revenue. For all three, a year-end catch-up tops them up if their final trailing figure is higher than the quarterly run-rate. Run this once per quarter close, alongside the matching fortnightly cycle.
